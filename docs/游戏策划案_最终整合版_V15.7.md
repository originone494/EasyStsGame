## 1. 游戏概述

本作是一款以卡牌构筑、多角色组队和一维距离管理为核心的回合制 Roguelike 小游戏。玩家操控一支共同占据一个格子的队伍，利用攻击、位移、击退、抽牌和消耗回收等效果应对左右两侧不断接近的怪物。

怪物不进行普通的主动攻击，而是在移动中实际接触队伍时造成接触伤害，非Boss怪物随后消失，不再接触后退；Boss采用独立输出挑战：接触玩家时结束战斗，累计伤害达到100%才成功，第一、二层Boss的超额伤害提高奖励，第三层Boss成功后不提供任何奖励。怪物之间存在实体阻挡；卡牌或明确效果造成的击退仍能传递剩余位移并形成连锁碰撞。非Boss战在所有怪物消失且队伍存活时结束，评分0%最差、100%最好；Boss战采用6.6节及12.5节的独立规则。玩家通过招募角色解锁新卡池和固定遗物，使单角色牌组逐步发展为多角色协同构筑。

### 1.1 核心体验

- **少量基础手牌、自由连续出牌：** 回合开始将手牌补至3张，通过额外抽牌及卡牌组合延长行动。
- **双向威胁管理：** 同时判断左右敌人的推进速度、接触伤害与消失后腾出的空间。
- **位移与碰撞策略：** 玩家可穿越怪物调整站位，击退则能改变怪物队列并引发连锁。
- **角色扩展构筑：** 招募同时提供卡牌、卡池和遗物，改变后续成长空间。
- **可预测的昼夜节奏：** 每3个完整回合切换昼夜，对应属性强化卡牌直接伤害。

## 2. 单局流程与楼层结构

### 2.1 单局循环

选择初始角色 → 建立7张初始牌组并获得角色固定遗物 → 进入当前楼层 → 按线性地图依次处理战斗、事件、火堆、商店 → 挑战本层Boss → 结算奖励 → 队伍未满时招募新角色 → 第1、2层后按后续楼层流程继续；第3层Boss挑战成功后直接进入最终通关结算，不发放任何奖励，不再招募。

已确定前三层的战斗配置如下，Boss计入每层战斗总数；精英也占据战斗名额，不额外增加总战数。

| 楼层 | 战斗总数 | 非Boss战斗 | 最后一战 |
|---|---:|---:|---|
| 第1层 | 10 | 9 | 第1层Boss |
| 第2层 | 7 | 6 | 第2层Boss |
| 第3层 | 5 | 4 | 第3层Boss |
| 合计 | 22 | 19 | 3场Boss战 |

前三层内普通战与精英战的具体配置、精英数量尚待设计。

### 2.2 线性地图

每层仅有一条推进路线，玩家依次完成节点，不选择分支。线性结构不代表每局节点内容和数量完全相同：特殊事件、火堆、商店可以随机生成并插入战斗之间，均不占用10／7／5场战斗的名额。

地图提前展示战斗提供的属性类型和奖励基准点数；实际奖励与战斗评分的关系见12.4节。事件若改变后续奖励，必须同步更新地图展示。特殊事件只显示“？”标记，具体内容在进入时揭晓。

### 2.3 非战斗节点生成约束

| 节点 | 生成规则 |
|---|---|
| 特殊事件 | 每层数量和位置随机，具体数量范围待配置 |
| 火堆 | 每层数量随机；其中一个固定紧邻Boss之前 |
| Boss前火堆 | 计入该层火堆总数，不在随机总数之外额外赠送 |
| 商店 | 每层至少1间，数量和位置随机，具体上限待配置 |

随机事件或商店不得插入“Boss前火堆 → Boss战”这一固定相邻关系中。

### 2.4 最终层与通关条件

第三层为最终层，全局共3层、22场战斗。第三层Boss接触玩家时，累计伤害达到100%即挑战成功并通关，进入最终结算；不足100%则本局失败。达到100%本身仍不提前结束Boss战，可继续输出争取更高评分。通关后不进入第四层、不再提供招募，也不提供任何奖励，包括金币、属性、卡牌和遗物；仅展示通关结果及伤害评分。

第一、二层通过后，队伍未满时各提供一次招募机会。开局1人，因此进入第2层时可为2人，进入第3层时可为3人；队伍上限为3人。



## 3. 队伍与角色系统

### 3.1 共位与共享资源

所有队员同时参战，共享同一个战场位置与队伍生命值，不设置队员独立站位、独立承伤和单独死亡退出机制。位移作用于整支队伍，玩家无需切换当前出战成员。

队伍初始最大生命、招募是否改变最大生命、各角色是否提供其他基础属性，尚待配置。原讨论中的30点生命等数字均为示例。

### 3.2 招募规则

1. 开局选择1名初始角色。
2. 通过第1层或第2层后，在队伍未满时选择1名新角色加入；第3层通关后不招募。
3. 招募后解锁其36种专属卡牌，纳入后续可获取卡池。
4. 每次招募新角色，连续进行3轮选卡：每轮从该新角色专属卡池生成3张候选，玩家选择其中1张加入实际牌组，完成3轮后共获得3张专属卡。每轮均遵守卡牌持有数量上限，已达到上限的卡不能再作为可获取候选。该规则适用于所有新招募角色，不改变开局7张初始牌组。
5. 同时获得该角色固定专属遗物。
6. 队伍达到3人后不能继续招募或替换；已招募成员不能主动退出。

每次招募从未入队的可招募角色中随机提供3名不同候选，玩家选择1名加入；可招募角色不足3名时展示全部可用角色，不重复凑数。队伍未满且存在可招募角色时，必须选择1名，不允许跳过招募；队伍已满或无可招募角色时不进入招募选择。候选生成权重尚未确定。招募选卡已确定为连续3轮三选一，不展示完整36种卡供自由挑选；每轮3张候选必须为不同卡名；不同轮次允许出现同名卡，也允许再次选择已选过的同名卡，但仍受各卡持有数量上限约束。每轮生成候选前，须按前面轮次选卡后的实际牌组重新检查持有上限。选卡稀有度权重尚待确定。

### 3.3 角色内容设计规范

每名角色拥有36种不同专属卡牌，围绕2～3种同等重要的核心机制展开，不设固定主次。攻击与技能比例依角色定位配置，不要求所有角色一致。

每个角色原则上采用普通60%、罕见30%、稀有10%的卡池结构，因36不能按此比例精确分割，整数分配可微调。原讨论中的22／11／3只是建议方案，并非已确认的固定数量。

跨角色联动通过通用行为与事件形成，例如位移、击退、碰撞、抽牌、消耗和回收。不设计必须由指定姓名角色组成队伍才能发动的专属组合技。

正式角色名单、角色数量、36张卡的具体内容和专属遗物效果，均属后续内容制作任务。

## 4. 卡牌、卡池与牌组循环

### 4.1 三种来源卡池

| 卡池 | 定位及来源 |
|---|---|
| 通用基础卡池 | 提供初始基本行动，开局获得5张；与无色卡池独立 |
| 角色专属卡池 | 每角色36种，当前队伍解锁的卡池用于招募选卡、战斗奖励等 |
| 无色卡池 | 独立于角色，通过商店和特殊事件获得，不进入战斗卡牌奖励 |

“通用／角色／无色”表示来源，“攻击／技能”表示战斗类型，两者独立。消耗和限量也属于独立属性，并非额外卡牌类型。初始5张基础卡和2张角色卡是否包含同名复制品、具体由哪些卡构成，尚待配置。

### 4.2 类型与稀有度

- **攻击牌：** 以造成伤害为主要用途，可附加位移、击退等效果。
- **技能牌：** 提供位移、抽牌、控制、增益、回收等效果，也可造成直接伤害。
- **稀有度：** 普通、罕见、稀有。
- **普通卡池比例不等于奖励概率。** 角色卡池的60／30／10结构不能直接充当战斗奖励抽取权重；相关权重尚待配置。

### 4.3 获取、重复与升级

**全局卡牌奖励候选规则：** 所有卡牌奖励的同一轮候选必须不同名，适用于普通战、精英战、Boss、招募及事件等选卡奖励，不因来源不同另设重复规则。多轮奖励允许跨轮重复出现或选择同名卡，仍遵守卡牌持有上限；持有上限须在每轮生成前更新检查。本规则不禁止牌组持有同名复制品。候选池不足时不得用同名卡凑数，具体不足处理统一待定。

普通战与精英战胜利后展示3张随机候选角色卡，玩家选1张加入牌组，也可以跳过。候选从当前所有已入队角色解锁的专属卡池合并池中随机抽取，不设置每名角色的候选配额，也不保证覆盖不同角色；3张候选可以全部来自同一角色。具体抽取权重仍待配置；同轮候选遵守全局不同名规则。精英战同样提供卡牌三选一，可跳过。第一、二层Boss挑战成功后提供3张稀有角色卡，选择1张或跳过；候选仅从当前已入队角色的合并稀有专属卡池随机抽取，遵守持有上限，不保证覆盖不同角色。Boss奖励选卡在本层招募前完成，因此不包含尚未入队的新角色卡池。第三层Boss通关后不提供卡牌或其他奖励。

大部分卡可以重复获得，少部分卡单独配置持有数量上限，达到上限后不能继续获得。同名卡的不同复制品独立升级，每张具体卡最多升级一次，具有普通版和升级版，升级内容按卡配置。

### 4.4 战斗内区域

| 区域 | 用途 |
|---|---|
| 抽牌堆 | 当前可抽取的卡牌 |
| 手牌 | 当前可打出的卡牌 |
| 弃牌堆 | 普通卡使用后或回合结束弃置的卡 |
| 消耗区 | 具有消耗属性的卡使用后进入，不参与普通洗牌 |

基础规则：

1. 玩家回合开始补手牌至3张；这不是固定额外抽3张。
2. 卡牌或其他效果可以额外抽牌，手牌允许超过3张；手牌硬上限尚未确定。
3. 玩家每回合可以打出任意数量的合法卡牌。
4. 普通卡使用后进入弃牌堆，消耗卡进入消耗区。
5. 回合结束，剩余手牌全部进入弃牌堆。
6. 抽牌时若抽牌堆不足，将弃牌堆洗成新抽牌堆，继续未完成的抽牌；同回合允许多次洗牌，洗牌无额外惩罚。
7. 消耗卡可通过明确的特殊效果回收，回收到哪个区域由效果决定。
8. 战斗结束后消耗卡恢复到牌组；消耗不等于永久删卡。
9. 允许玩家通过卡牌构筑，在同一回合反复抽牌、洗牌和攻击，形成可持续操作的无限连招；成功构筑此类组合属于允许的构筑奖励，不仅因其可无限重复而削弱或禁止。每次出牌仍须满足具体卡牌条件，战斗胜负中断规则照常适用。

正在执行的卡何时正式移入弃牌堆、抽弃牌堆均为空时的抽牌处理等实现细节，未通过访谈明确，应在实现前写入执行规格，不能用改变已确认循环方式来暗中补齐。

## 5. 战场、攻击与位移

### 5.1 空间规则

战场为有限的一维整数格子区间，左右各有边界。队伍和怪物不能移动到边界以外。战场具体长度、各战斗初始位置和生成方式待配置。

一维距离为队伍坐标与目标坐标之差的绝对值，用于威胁展示、推进和事件排序等。距离不构成卡牌攻击射程。

### 5.2 玩家移动

队伍不能免费主动移动，只能使用卡牌或明确效果改变位置。主动位移可以穿过怪物，不因穿越受到接触伤害，但终点不能停在怪物占据的格子，也不能越出战场。

对于非法终点，是禁止确认、允许重新选择，还是由特定卡牌采用其他处理，尚未确定。不得默认将队伍与怪物重叠作为合法结果。

### 5.3 攻击选择

常规单体攻击操作为“选择卡牌 → 点击目标敌人 → 执行”。可以直接选择队伍任意一侧的敌人，不先选左／右方向；没有最小或最大射程，也不会因为其他怪物挡在目标前方而无法选中。

单体与群体攻击共存，群体目标集合按卡牌文字确定。卡牌可独立规定出牌时锁定目标或执行动作时自动索敌，必须明确描述。

多段攻击一旦对某目标展开，目标死亡或因明确条件失效后，停止针对它的剩余段数，不自动转移到其他敌人。未执行段不产生伤害事件。卡牌上的独立后续动作仍可继续；最后怪物死亡后按第11节完成当前卡牌及相关触发收尾。玩家死亡与Boss接触终止例外。

### 5.4 群体伤害

一次群体伤害先确定目标集合，对各目标独立计算伤害，再作为同一批次同步更新生命、统一判断死亡。它不是按敌人距离逐个伤害。

群体伤害之后的独立动作按卡牌文字执行。若该同步批次已达到胜负条件，先完整完成批次；玩家死亡立即失败，最后怪物死亡则按第11节进入收尾结算。

## 6. 怪物行动与接触伤害

### 6.1 怪物基础配置

怪物至少配置最大生命值、当前生命值、每回合正常前进距离、接触伤害、初始位置以及本场固定编号。不同怪物拥有不同速度；界面提前展示下一次移动距离。不再配置接触后退距离。

没有已定案的具体怪物名单、普通攻击技能表或统一伤害数值。原记录中的普通怪、迅捷怪、重型怪均为机制示例。

### 6.2 正常前进

玩家结束回合、弃置剩余手牌后，怪物逐只行动。一只怪物完成全部正常移动、接触处理及相关事件队列后，才轮到下一只；不采用同步推进。怪物不能重叠或互相穿过，也不能通过正常前进推动其他怪物。每个怪物回合开始时，按怪物与队伍的距离由近到远排序，距离相同则按本场固定编号从小到大排序。本回合行动顺序锁定，不因队伍位移、怪物击退或其他位置变化重新排序；轮到已死亡或消失的怪物时跳过。

每只怪物行动时读取当前战场，可以进入此前怪物已移动或消失后腾出的格子；不能预先进入其他怪物尚未腾出的格子。若受阻则停止并清除剩余正常前进距离，普通阻挡不产生击退碰撞事件。

### 6.3 接触处理流程

1. 当前行动怪物实际接触队伍时，立即清零其剩余正常前进距离并处理接触；其他怪物此时尚不进行正常移动。
2. 普通逐只行动不会产生同步推进接触队列。若独立群体效果导致多只怪物同时接触，仍按固定编号从小到大处理该效果产生的接触队列；这不决定正常行动顺序。
3. 轮到每只怪物时，重新检查是否仍在场、是否仍接触队伍；不满足则取消其本次接触结算。
4. 非Boss合法接触造成接触伤害，随后移出战场，不执行后退，不产生击退或碰撞。Boss接触按6.6节立即结束战斗；接触不造成伤害、不扣生命，直接按累计伤害是否达到100%判定胜负。
5. 接触伤害使队伍生命归零或以下时立即失败；不能因最后一只怪物消失而改判胜利。
6. 怪物消失后若队伍存活且场上已无怪物，立即结束战斗并进入评分奖励流程；否则处理相关事件队列，待当前怪物全部处理完毕后，才开始下一只怪物的行动；若为独立效果产生的同时接触队列，则先完成该队列。

取消接触结算不会恢复该怪物已经清零的正常前进距离。已经死亡或消失的怪物不再执行未完成行动。接触伤害即使为0，合法接触后的非Boss怪物仍消失；Boss接触则按6.6节终止战斗。

### 6.4 剩余前进距离与腾空位置

| 发生情况 | 剩余正常前进距离 |
|---|---|
| 实际接触队伍，即使稍后接触结算被取消 | 清零；完成合法接触后非Boss怪物消失；Boss接触终止战斗 |
| 正常前进受到其他怪物阻挡 | 清零 |
| 未接触队伍，仅被明确击退效果撞开 | 保留，从新位置继续使用 |

已结束正常前进的怪物，不因被撞开或前方怪物消失重新获得移动距离。尚未行动的怪物在轮到时，以及当前仍有剩余前进距离的怪物，可以进入前方怪物已消失后腾出的格子，仍须遵守不可重叠和正常阻挡规则。

### 6.5 消失、击杀与评分记录

非Boss怪物生命归零时死亡并移出战场；完成接触后也会移出战场，但接触消失不等于被击杀，不将剩余生命强制扣至0，不产生该怪物的伤害、生命减少或死亡事件，不触发击杀奖励。两种移出方式均计入“所有怪物消失”的战斗结束条件。Boss不适用生命归零死亡规则，按6.6节接触终止。

移出怪物时保留其评分记录，不将它从本场评分分母中删除。同一非Boss怪物完成合法接触后已不存在，因此取消其原重复接触规则。Boss首次合法接触即结束战斗，不存在重复接触。

玩家主动位移穿越怪物仍按5.2节处理，不因穿越触发接触伤害或怪物消失。“实际接触”的精确格子检测阈值与表现方式仍需在实现规格中明确，并统一用于预览和实际结算。

### 6.6 Boss输出挑战

Boss正常受到卡牌、遗物及明确效果造成的击退，击退距离不因Boss身份减半或免疫。玩家可以通过击退延迟Boss接触，争取更多输出时间；击退沿用第7节的实体阻挡、剩余位移传递与边界规则，达到边界后的剩余位移消失。

Boss最大生命值作为100%伤害目标基准，必须为正数。独立记录对Boss的累计有效伤害；达到或超过基准不使Boss死亡、不移除Boss、不提前结束战斗。Boss继续推进，仍可被选中和承受后续攻击，累计伤害可超过100%。

- Boss首次合法接触玩家时立即结束战斗，锁定接触前已完成的伤害；取消剩余动作和待处理触发，即使场上还有小怪也结束。
- 累计伤害≥100%（含恰好100%）成功，<100%失败；110%、150%等评分均有效，达到奖励上限前越高奖励越好。
- 达到100%不产生死亡或击杀事件，多段攻击不因此中断。采用独立伤害计数，不以负生命值伪造生命减少事件。
- Boss接触不造成伤害、不扣生命，不产生接触伤害或生命减少事件，仅作为战斗终止与评分判定条件；接触前队伍生命归零仍立即失败。
- Boss接触时累计伤害不足100%，本局立即结束，玩家需重新开始新的一局；不能重试本场或继续下一层，不发放本场成功奖励，不提供招募机会。局外解锁等系统仍按原待设计项处理。

## 7. 击退、碰撞与边界

本节仅适用于卡牌、遗物或其他明确效果造成的击退；怪物接触玩家后不会自行后退。

### 7.1 剩余位移传递

本作采用游戏化的“动量守恒”：以尚未消耗的击退格数作为可传递量，不引入真实物理质量、速度或弹性系数。

后退怪物撞到另一只怪物时，撞击者停止，将剩余击退量传给被撞者；被撞者沿同方向继续移动，遇到第三只怪物可继续传递。已经实际移动过的格数不能再次传递。

若被撞者本身也有剩余同向击退量，两者相加。群体击退所有目标同步参与位移和冲突处理，不按远近逐只完成。

示例：碰撞瞬间A剩余2格、B自身剩余1格，A撞B后A剩余量为0，B剩余量为3格。此例不代表额外产生位移。

### 7.2 边界

怪物撞到边界停止，不能出界，剩余击退量消失。撞墙默认不产生额外伤害，也不自动视为怪物间碰撞事件。

### 7.3 碰撞事件

每次实际怪物间碰撞产生一个独立事件，一次连锁中的多次碰撞分别记录。同一时刻多个碰撞事件按碰撞位置从左到右入队；同一位置同时发生多次碰撞的次级排序尚待确定。

碰撞本身默认不造成伤害。遗物或卡牌决定是否响应、产生何种效果、影响哪名参与者，以及能否继续连锁。普通前进阻挡与后退碰撞必须区分。

相反方向的击退同时冲突、碰撞坐标的精确取值以及多重同步冲突的离散执行方法，尚未完整定案；实现需满足已确认的同步、不可穿越和位移量不凭空增加约束。

## 8. 昼夜与属性成长

### 8.1 昼夜周期

每场战斗独立随机初始白天或黑夜，初始概率待配置。每个时段持续3个完整回合，在第4、7、10……个玩家回合开始时切换。

顺序为：**先切换昼夜 → 处理回合开始效果 → 补手牌至3张 → 玩家行动。** 怪物行动阶段不会因自然周期中途切换。明确的卡牌、遗物或事件效果可以规定昼夜例外。

### 8.2 伤害属性

目前正式属性为白天增伤、黑夜增伤。每1点对应属性提供1%的当前时段卡牌直接伤害加成，同一属性内部点数线性累加。

攻击牌和技能牌直接造成的伤害享受对应昼夜属性。遗物伤害、碰撞相关间接伤害不自动享受加成，即使碰撞由卡牌击退引发，也要区分伤害来源。

同一属性100点表示一个+100%的倍率，即×2，不是把100个+1%分别相乘。

### 8.3 属性来源与上限

战斗胜利后直接增加该战斗指定类型的属性，普通战主要提供一种，精英战与Boss可同时提供多种。

同一楼层越接近末尾，属性奖励逐步增加，具体曲线待配置。每项属性拥有独立楼层上限，同层各项上限相同，进入更高楼层后同步提高。50／100／200只是讨论用示例，不是正式平衡值。

结算公式：

`新属性 = min(当前属性 + 本次奖励, 当前楼层上限)`

溢出部分直接消失，不暂存、不转化、不在下一层返还。事件获得的属性也遵守这一规则。Boss奖励仍受其所在楼层上限约束。

## 9. 伤害计算与生命减少

### 9.1 单段伤害公式

没有特殊保底描述时：

`D = max(0, ceil((B + F) × M1 × M2 × … × Mn))`

- B：该段基础伤害。
- F：所有适用的固定数值修正之和。
- M：各项适用的独立百分比修正倍率。
- ceil：向上取整。

顺序为：基础伤害 → 固定数值修正 → 全部百分比倍率相乘 → 向上取整一次 → 检查伤害下限。

第156题最终选择B，确认多个百分比增伤分别乘算。例如基础10、增伤20%和30%，计算为10×1.2×1.3＝15.6，向上取整为16。

同一个公式中间保留小数，不逐步取整；不同独立动作、不同伤害段分别完成公式并取整。多段伤害不能先合计基础值再统一取整。

默认最低伤害为0，负伤害不转化为治疗。特殊卡牌可明确规定保底伤害，其与免疫等尚未设计机制的交互不自动确定。

### 9.2 两种基础概念

| 情况 | 受到伤害 | 失去生命值 |
|---|---|---|
| 发生伤害结算，最终伤害0 | 是 | 否 |
| 发生伤害结算，生命未减少 | 是 | 否 |
| 伤害实际扣除生命 | 是 | 是 |
| 直接生命消耗导致生命减少 | 否 | 是 |
| 直接生命消耗为0，生命不变 | 否 | 否 |

“受到伤害”以伤害结算发生为依据，0点也成立。“失去生命值”以生命实际减少为依据；它既可由伤害引起，也可由非伤害效果引起。

直接“失去生命值”不是伤害，不产生伤害事件，不适用伤害减免或护盾抵扣。护盾、免疫、其他防御机制的具体持续和吸收规则尚未完整设计，本稿中的分类不等于新增一套防御系统。

### 9.3 生命代价

卡牌必须明确写出“受到X点伤害”或“失去X点生命值”，由文字决定类型，不因它是出牌代价而统一归类。

允许打出名义生命代价等于或高于当前生命的卡，不显示额外致命警告，不要求二次确认，原有卡面代价正常展示。实际支付导致生命归零或以下时立即失败，卡牌收益不执行。

对于“受到伤害”型代价，先按适用规则完成伤害结算，再根据实际生命判断是否死亡。该代价产生的事件先记录入队，若存活，先继续卡牌直接效果，卡牌执行结束后再处理事件触发。

第140题保留“其他出牌条件和非生命资源不足时不能打出”的原则，但其能量例子不构成新增通用能量系统；本作仍无通用能量。

### 9.4 生命减少事件

每次实际生命减少独立记录减少量。一次伤害同时减少生命时，先记录伤害事件，再记录失去生命值事件。多段攻击每段各自记录，不合并扣血。

例如3段伤害实际扣血2、0、2，事件顺序为：伤害① → 失去生命值①（2）→ 伤害② → 伤害③ → 失去生命值③（2）。

默认“失去生命值时”响应所有来源的实际生命减少。若仅响应伤害扣血或非伤害消耗，必须在效果中明确限制。

### 9.5 效果措辞

不使用含糊的“成功造成伤害”作为正式条件，应明确写成：

- “发生伤害结算后”：0点也满足。
- “造成大于0的伤害后”：数值必须为正。
- “使目标生命值减少后”：必须实际扣血。

没有合法目标而跳过伤害动作，不等于造成0点伤害，未发生的结算不产生伤害事件。

## 10. 事件队列与触发效果

### 10.1 执行、记录、触发三层分离

直接动作立即更新战场；事件用于记录发生的事实；外部触发效果在规定的处理点执行。事件入队不等于立即触发。

玩家打出一张卡牌，按描述顺序完成全部可执行的直接动作，期间收集事件；卡牌直接效果结束后再处理队列。玩家死亡立即中断并失败；最后怪物死亡不取消当前卡牌及其相关触发，按第11节收尾。Boss接触仍按6.6节立即终止。

怪物回合采用不同处理点：每只怪物完成接触伤害及对应接触处理后（非Boss消失；Boss按6.6节终止战斗），若战斗尚未结束，立即处理相关队列，再继续其他怪物行动。

### 10.2 队列顺序

事件先进先出。处理当前事件触发的全部效果后再处理下一个；响应效果产生的新事件加入队尾，不插入当前事件的响应之间。

卡牌与遗物提供的触发效果不按类别分优先级，统一按效果登记时间排序。登记时间指开始参与监听的时间，不是卡牌获得时间。遗物之间必须保持获得顺序；临时卡牌监听在实际生效时登记。

### 10.3 各类排序规则

| 情况 | 已确认排序 |
|---|---|
| 不同独立动作产生事件 | 按动作实际执行先后入队 |
| 多段攻击 | 每个实际执行段独立记录 |
| 群体伤害 | 每个目标独立产生伤害事件；状态仍同步生效 |
| 同一次群体伤害的伤害／死亡两类事件 | 全部伤害事件先于全部死亡事件 |
| 同类群体伤害事件、同时死亡事件 | 距离队伍由近到远，相同则怪物固定编号从小到大 |
| 同时发生的碰撞事件 | 碰撞位置从左到右 |
| 独立群体效果导致多只怪物同时接触队伍 | 按固定编号从小到大处理；普通怪物行动为逐只执行 |
| 同次伤害与该次生命减少事件 | 伤害在先，失去生命值在后 |

每只非Boss怪物真正死亡独立产生一次死亡事件；不会把多只死亡合并为一次。接触消失不产生死亡事件。最后一只怪物死亡时保留当前卡牌及其相关触发链的事件，包括最后击杀的死亡事件，按第11节收尾；接触消失的终止规则不变。

“失去生命值”新增事件与多目标同步伤害、死亡事件的完整跨类型排列尚未通过访谈单独确定。实现前须补齐这项细则，同时满足上表已确认的相对顺序，不应自行宣称第144题已经确定了所有群体事件的合并顺序。

### 10.4 遗物触发资格与数值快照

一个事件出队、开始处理时，统一判断并锁定各遗物的触发资格，同时锁定不依赖所选目标状态的效果数值。这里读取的是事件开始处理时的当前状态，而非事件最初产生时的历史状态；引用事件自身数值时读取事件记录。

之后按遗物获得顺序执行。前序效果改变队伍生命、手牌等状态，不重新判断后续遗物已锁定资格，也不改变已锁定数值。

自动选目标在轮到该遗物实际执行时进行。依赖目标状态的数值，在选定目标后读取目标当时状态计算；同一公式混合两类数值时分别取值，再完成公式。

示例：事件开始处理时队伍已损失10生命，“获得等于已损失生命值的护盾”锁定为10；前序遗物治疗后，该数值不变。若效果是“伤害等于所选敌人当前生命的一半”，则执行时选敌，再读取敌人生命并向上取整。

以上资格与数值锁定是已明确针对遗物作出的决定；临时卡牌监听是否采用完全相同快照策略，尚未明确，不在本稿自动扩展。

### 10.5 目标失效与独立部分

遗物执行时没有合法目标，跳过依赖目标的动作，继续可独立执行的其他部分。“然后”只表示先后顺序，不自动构成成功前提；需要依赖前一步结果时必须明确写出条件。

本轮早先“2格内没有敌人”的示例仅用于解释目标失效，不能推翻原设定的无射程规则。实际内容应使用死亡、目标类别不符合等明确条件解释无合法目标，不能据此擅自加入距离射程。

### 10.6 遗物次数与连锁权限

每件遗物独立配置触发条件、次数限制和连锁权限。可存在无限次、每回合限次、每场战斗限次及持续生效型遗物。角色专属遗物和通用遗物适用相同框架。

遗物是否允许其产生的事件继续触发其他遗物，由该遗物配置决定。次数限制与连锁权限相互独立。

不设置统一全局连锁次数上限，也不添加隐藏次数截断。玩家可主动持续操作的无限抽牌、洗牌和攻击组合属于允许的构筑奖励。自动触发链若无法结束、无法达到战斗结束条件且无法交还玩家操作，则属于阻塞游戏的死循环，通过具体卡牌、遗物条件、次数和权限设计及组合测试解决；不得将此要求扩大为禁止玩家的无限连招。

## 11. 战斗胜负与中断优先级

每个可独立完成的动作或不可分割同步批次结算后，立即检查胜负：

1. 队伍生命值归零或以下：立即失败。
2. 非Boss战：队伍存活且所有怪物消失时满足结束条件；最后怪物死亡时先完成下述收尾，最后怪物接触消失时立即结束，再按生命损失评分结算。Boss战：Boss接触玩家即结束，累计伤害≥100%成功，<100%失败；达到100%本身不提前结束战斗，场上其他怪物不影响Boss接触终止。
3. 非Boss战中双方同时死亡或最后怪物接触致死均按失败处理。Boss接触前队伍死亡仍立即失败；Boss接触不扣生命，按接触前累计伤害≥100%成功、<100%失败判定；未达标失败直接结束本局，需重新开局。

最后怪物死亡时先进入收尾阶段：停止其他单位行动，不允许玩家继续主动出牌或开始新回合。目标死亡后取消针对它的剩余攻击段，不自动转移目标，未执行段不产生事件；当前卡牌其余合法动作（如治疗、抽牌）继续完成。随后按原队列规则完成当前卡牌及其相关触发链，包括击杀、死亡监听及这些触发继续产生的事件。没有合法敌方目标的动作跳过，独立其他动作照常执行；相关队列处理完且队伍存活后，才正式进入奖励界面。若最后击杀由遗物等触发造成，则完成当前触发链的相关收尾。

收尾期间玩家生命归零仍立即失败，取消剩余动作与触发，不能靠后续治疗补救。玩家死亡、Boss接触终止，以及非Boss最后怪物接触消失的立即终止规则保持不变；这些立即终止会取消剩余动作和队列。已完成结果不回滚。

同步效果必须作为整体生效后再检查，不因遍历目标先后造成不同结果。顺序动作则不能等待后续治疗补救：先扣血致死、后治疗的卡牌在扣血后立即失败。

战斗胜利奖励流程与战斗内事件队列区分。最后击杀监听在战斗收尾阶段正常执行一次，不会因奖励结算再次执行；若未来设计战斗胜利后恢复等效果，应另行明确其属于战后流程。

## 12. 战斗奖励与遗物获取

### 12.1 战斗奖励矩阵

下表保留各战斗的奖励项目与基准配置。评分仅影响金币和属性奖励；卡牌奖励的提供规则、候选数量与稀有度规则，以及Boss遗物的数量与品质均不因评分变化。非Boss战金币与属性映射见12.4节，Boss战见12.5节。

| 奖励 | 普通战 | 精英战 | Boss战 |
|---|---|---|---|
| 金币 | 基础量 | 比普通战多 | 第1、2层最高档；第3层无 |
| 属性 | 指定一种 | 可同时多种 | 第1、2层同时多种；第3层无 |
| 角色卡三选一 | 有，可跳过 | 有，可跳过 | 第1、2层：3张稀有角色卡选1，可跳过；第3层无 |
| 通用遗物 | 无 | 无 | 第1、2层各随机1件；第3层无 |
| 招募 | 无 | 无 | 完成第1或第2层后、队伍未满时提供机会 |

金币金额、奖励属性数量曲线及Boss战后完整界面顺序待配置。属性奖励不通过经验或等级发放。

### 12.2 两类遗物

每名角色固定1件专属遗物，在选择初始角色／招募时获得。通用遗物独立于角色，只有商店和Boss奖励两种直接获取途径，普通战、精英战、火堆和特殊事件均不直接赠送。

通用遗物分普通、罕见、稀有三档，总数量和各稀有度制作比例不设固定限制，随内容持续扩充。

### 12.3 Boss遗物奖励与品质

| Boss | 正常奖励 |
|---|---|
| 第1层 | 随机1件普通通用遗物 |
| 第2层 | 随机1件罕见通用遗物 |
| 第3层 | 不发放通用遗物；挑战成功后通关 |

仅第1、2层Boss成功后随机发放通用遗物，不进行三选一；第三层Boss不发放通用遗物，也不将该奖励提前发放。同一局禁止重复获得通用遗物，已持有的从后续商店与Boss奖励池排除。

某档遗物池耗尽时，改从仍有可用遗物的档位抽取。商店排除耗尽档位后按剩余原权重归一化；Boss替代抽取的具体档位权重尚待配置。所有档位全部耗尽的处理尚未确定。

### 12.4 非Boss战生命损失评分与奖励

本节仅适用于非Boss战。战斗结束后，根据本场怪物失去的生命值计算0%～100%的评分。100%对应最好奖励，0%对应最差奖励；0%不自动等于没有奖励。玩家失败仍按失败流程处理。

为使基础战斗可计算，暂采用以下实现口径：按生命值总量加权，不按怪物数量平均。

`评分 = clamp(本场怪物有效生命损失总和 ÷ 本场怪物最大生命值总和, 0, 1) × 100%`

- 只记录实际扣除的怪物生命值；卡牌、遗物和碰撞相关效果造成的实际生命损失均可计入。
- 过量伤害不计入；单只怪物累计计分最多为其计分最大生命值。
- 接触消失不扣除怪物剩余生命，不增加计分；消失后仍保留该怪物的分子、分母记录。
- 示例：两只怪物各10生命，一只被击杀，另一只失去5生命后接触消失，评分为15÷20＝75%。
- 所有怪物未损失生命就接触消失，对应0%；所有怪物的计分生命均被扣除，对应100%。

以上总生命加权口径为本次修订的暂定实现解释。未来若加入怪物治疗、复活、召唤或最大生命变化，须补齐计分归属和分母规则，避免通过重复扣血刷分。

评分仅影响金币和属性奖励。卡牌与通用遗物按原有规则获得，不因评分降低而取消、减少或降低品质；精英战提供卡牌三选一且可跳过；第一、二层Boss成功后提供稀有角色卡三选一且可跳过，候选品质不受伤害评分影响。招募机会不受评分影响。

金币和属性均采用20%保底的连续线性奖励，不采用评分分档。设评分比例s为0～1，满额奖励为该场战斗的基准奖励：

奖励比例 = 20% + 80% × s

实际奖励 = ceil(基准奖励 × 奖励比例)

沿用全稿最终向上取整规则，金币和每项属性分别计算并只在最终取整一次。0%评分获得20%基准奖励，50%评分获得60%，100%评分获得全额；基准奖励为0的项目仍为0。属性奖励先按评分计算并取整，再应用楼层属性上限，超出上限部分仍作废。保底仅适用于队伍存活并完成战斗的正常奖励结算，不适用于失败。

### 12.5 Boss累计伤害评分与奖励

所有Boss均按累计伤害是否达到100%判定成功与失败。以下奖励公式仅适用于第一、二层Boss；第三层Boss成功后不提供任何奖励，无论伤害评分多高，仅进入通关结果展示。

`Boss评分 = 对Boss累计有效伤害 ÷ Boss最大生命值基准 × 100%`

计入按伤害公式及适用减免结算后的有效伤害，包括卡牌、遗物和明确碰撞伤害；不按Boss剩余生命截断，过量部分及达到100%后继续造成的伤害均计入。0点伤害不加分，小怪受到的伤害不计入Boss评分。直接失去生命等非伤害效果如何作用于Boss及计分，须随具体内容明确。

评分≥100%才成功。Boss累计伤害评分可超过100%；金币和属性奖励在达到奖励上限前，与伤害比例同比例增加。110%伤害对应110%基准奖励，200%伤害对应200%基准奖励，但均受奖励上限约束。卡牌与遗物按此前规则提供。

设伤害比例s = 累计有效伤害 ÷ Boss基准最大生命值，奖励倍率上限为C = 5，即基准奖励的500%：

实际奖励 = ceil(基准奖励 × min(s, 5))，仅在s≥1的成功结算中适用。

金币和每项属性分别计算，最终向上取整一次。伤害评分达到500%时获得500%基准奖励；评分600%、1000%等仍按500%发放。达到上限后继续造成伤害仍可提高显示评分，但不再增加奖励。

非Boss战20%保底不适用于Boss未达标失败。Boss属性奖励仍受当前楼层属性上限限制：先按伤害比例计算奖励（最多5倍基准）并向上取整，再应用楼层属性上限；超出部分直接作废，不暂存、不转化、不在下一层返还。金币不受属性楼层上限影响。

已允许的无限出牌组合可持续提高Boss伤害评分，但金币和属性收益受奖励上限限制；奖励上限不限制出牌次数或累计伤害。

## 13. 商店与经济

### 13.1 标准库存

| 项目 | 数量或使用次数 |
|---|---:|
| 角色卡牌 | 5张 |
| 无色牌 | 2张 |
| 通用遗物 | 3件 |
| 付费删卡 | 每店最多1张 |
| 付费升级 | 每店最多1张 |

进入时随机生成商品，售出后不自动补货；同一商店遗物不得重复，排除本局已持有遗物。商店角色卡是否严格限定当前队伍卡池，在原记录中仅有建议，须在商品生成表确认。

### 13.2 商品定价

角色卡按普通／罕见／稀有分档，无色牌使用相同稀有度基础价，无额外来源溢价；通用遗物按其稀有度分档。每件商品在基础价上下约10%独立浮动，生成后价格保持稳定，不因购买或重进界面重新随机。

具体基础价和随机分布待配置；±10%不自动应用于删卡及升级服务。已确定的数值公式默认在最终结果向上取整，价格若需独立取整规则应明确标注。

### 13.3 服务费用

删卡永久移除牌组中的指定可删除卡。商店升级只可选择尚未升级的卡，每张卡仍最多升级一次。

两项服务独立计数、独立限额、独立涨价。只在成功完成对应付费服务后累计，跨商店和楼层不重置；火堆和事件中的相应操作不计入商店付费次数。升级收费不因卡牌稀有度或来源不同而改变。

首次价格、涨幅和增长函数待配置。原记录中“初价＋次数×涨幅”属于建议实现，不作为已确认固定公式。

### 13.4 商店遗物概率

每个遗物商品位按普通60%、罕见30%、稀有10%抽取稀有度，所有楼层相同，再从可用池抽取具体遗物。该概率不要求每店固定出现某种组合，也不要求实际制作的遗物数量遵循该比例。

例如普通池耗尽后，罕见与稀有按30:10重新分配为75%和25%。同店不得重复，池不足时的整体空位策略仍需随“全部耗尽”规则补齐。

## 14. 火堆与恢复

每次火堆在恢复生命和升级一张尚未升级的卡之间二选一。休息恢复队伍最大生命值的50%；这是恢复量，不是将当前生命设置为最大值的一半。

恢复量出现小数时沿用最终向上取整原则。治疗是否统一封顶最大生命、是否允许任何特殊溢出效果，应纳入生命系统完整配置，不从讨论示例擅自推导特殊机制。

Boss前火堆用于让玩家在生存与强化之间选择，不额外赠送一次行动。火堆升级不影响商店付费升级涨价次数。

## 15. 特殊事件

### 15.1 事件生成

每层地图生成时，决定事件节点数量、位置及每个节点的具体事件。候选来自通用事件池和本层专属事件池。地图只显示“？”，进入后揭晓；同一节点不因退出重进刷新内容或刷取随机结果。

事件内容预生成与结果随机的发生时机是两个概念。随机结果是在生成时固定还是选择后判定尚待配置，但必须避免重复进入刷新结果。

### 15.2 事件形式与权限

允许纯奖励、风险交易、随机结果、特殊机制四类混合。事件池不设固定数量，按机制需求持续扩充。

事件可以影响金币、生命、无色牌、卡牌升级／删除／复制／明确改造、属性、临时战斗状态、昼夜例外以及后续战斗奖励。具体事件必须写明范围、持续时间和代价。

事件仍遵守属性楼层上限与溢出规则，不直接赠送通用遗物，不重新引入等级经验。改变后续属性奖励时，地图立即同步更新。

正式事件名单、权重、重复规则和数量范围待设计；原记录的旅行者、祭坛等名字不自动加入正式内容。

## 17. 内容配置与开发拆分

本节为实现建议，服务已确认玩法，不额外增加正式游戏机制。

### 17.1 建议配置表

- **角色表：** ID、名字、2～3核心机制、36种卡牌ID、初始角色卡、固定遗物ID。
- **卡牌表：** ID、来源、类型、稀有度、目标规则、动作顺序、明确代价、消耗标记、持有上限、升级版。
- **遗物表：** ID、来源／稀有度、监听事件、资格条件、数值依赖、目标规则、次数限制、连锁权限。
- **敌人表：** ID、生命、速度、接触伤害及表现资源；战斗实例分配固定编号。
- **战斗表：** 楼层、序号、敌人组合、战场长度与初始坐标、属性与金币奖励基准、评分奖励映射。
- **地图表：** 战斗骨架、非战斗节点数量范围、Boss前火堆约束。

### 17.2 建议原型顺序

1. 实现一维战场、共享生命、基础牌区、补至3张及连续出牌。
2. 实现怪物逐只完整行动、接触处理与消失、效果击退与位移传递。
3. 实现事件队列、监听登记、遗物快照和即时胜负中断。
4. 实现昼夜、属性、公式及多段／群体伤害。
5. 接入招募、线性楼层、生命损失评分与战后奖励、火堆、商店、事件。
6. 扩充角色与36种专属卡池、敌人和Boss内容，进行数值测试。

原型可用临时内容验证规则，但不得将临时卡名、价格、怪物参数伪装为最终平衡配置。

| 主动位移穿越怪物 | 允许穿越，不受接触伤害；终点不得占怪物格 |
| 远处敌人且前方有其他怪物 | 普通单体攻击仍可直接选它 |
| 多只怪物进行正常行动 | 回合开始按距离由近到远、同距离按编号升序锁定顺序；当前怪物完整行动后才轮到下一只 |
| 行动中怪物或队伍位置改变 | 不重排行动顺序；已死亡或消失的怪物跳过 |
| 正常前进被怪物挡住 | 停止，剩余前进作废，不推动、不产生击退碰撞事件 |
| 未接触队伍的怪物被撞开 | 保留原未消耗正常前进距离 |
| 怪物接触后尚未轮到结算即被推离 | 取消本次接触伤害及消失，正常前进距离仍为0 |
| 群体伤害击杀多只但不是全部 | 同步伤害／死亡，分别记录事件并按已定规则入队 |
| 非Boss怪物完成合法接触 | 造成接触伤害后消失，不后退，不算击杀，不增加怪物生命损失计分 |
| Boss接触，累计伤害99% | 未达标失败，本局结束；不能重试本场或进入下一层，需重新开局 |
| Boss接触，累计伤害100%或110% | 接触不扣生命，判定成功，110%按同比例计算奖励并受奖励上限约束 |
| Boss未接触，累计伤害达到100% | 不死亡、不触发击杀、不结束，继续推进和承受伤害 |
| 对Boss施加击退 | 正常执行完整击退距离，受碰撞与边界规则约束，可延迟接触；不因Boss身份减半或免疫 |
| Boss场小怪全部消失但Boss尚未接触 | 战斗继续 |
| 第三层Boss接触时累计伤害达到100% | 挑战成功并通关，进入最终结算，无第四层及后续招募，不发放金币、属性、卡牌、遗物或其他奖励 |
| 非Boss接触伤害为0 | 该怪物仍消失 |
| 评分降低但队伍存活并完成战斗 | 仅影响金币和属性；卡牌、遗物与招募按原规则提供 |
| 最后一只怪物接触消失，队伍存活 | 战斗立即结束，进入评分奖励流程 |
| 最后一只怪物接触造成致命伤害 | 玩家失败，不按成功结束结算奖励 |
| 两只各10生命怪物，一只被击杀，另一只损失5生命后接触消失 | 暂定总生命加权评分为75% |
| 无Boss战中所有怪物满血接触消失，队伍存活 | 评分0%，金币与属性按20%基准奖励分别向上取整，再应用属性上限 |
| 评分50%，基准金币100、某项属性10，属性未触及上限 | 奖励比例60%，获得60金币和6点该属性 |
| 非Boss战评分100% | 金币与属性按全额基准奖励发放，属性仍受楼层上限限制 |
| 非Boss战造成过量伤害 | 只按实际扣血计分，评分不超过100% |
| Boss基准生命100，累计有效伤害110 | 评分110%，超额伤害有效 |
| Boss伤害评分500%或600%，基准金币100 | 均获得500金币；属性同样按最多5倍基准计算，仍受楼层属性上限约束 |
| 0点伤害 | 产生伤害事件，不产生生命减少事件 |
| 伤害实际扣血 | 先伤害事件，再生命减少事件 |
| 直接失去生命 | 只产生实际生命减少事件，不产生伤害事件 |
| 10伤害，增伤20%和30% | 乘算后15.6，最终16 |
| 基础5×50%×150% | 3.75，最终4，不逐步取整成5 |
| 3段基础2伤害，对应增伤17% | 每段3，全部执行时总计9 |
| 前序遗物治疗，后序数值依赖已损失生命 | 后序使用事件处理开始时锁定数值 |
| 前序遗物击杀自动目标但还有敌人 | 后序遗物执行时重新按规则选目标 |
| 后序伤害依赖目标当前生命 | 选目标后读取该目标当时生命计算 |
| 击杀最后敌人后还有抽牌或治疗 | 停止对死亡目标的后续攻击，完成当前卡牌其他效果及相关触发后进入奖励 |
| 最后击杀触发治疗 | 收尾阶段正常执行；若此前玩家已死亡则立即失败，不能补救 |
| 生命代价致死，卡牌后有治疗 | 立即失败，治疗不执行，无额外警告或确认 |
| 同步效果使队伍与最后敌人同时死亡 | 玩家失败 |
| 已到楼层属性上限再获得点数（含Boss奖励） | 超出部分作废，下层不返还 |
| Boss结算前属性95、楼层上限100、评分奖励计算结果20 | 实际增加5点，剩余15点作废 |
| 已有遗物出现在后续奖励候选中 | 排除，不允许重复获得 |
| 商店升级后去下一商店 | 次数重新可用，整局价格计数不重置 |
| 玩家构筑形成可持续操作的无限抽牌／攻击连招 | 允许，属于构筑奖励；正常执行出牌条件与战斗胜负中断 |
| 自动触发闭环无法结束且无法交还玩家操作 | 属阻塞游戏的内容设计缺陷，调整相关配置，不暗加全局次数上限 |
