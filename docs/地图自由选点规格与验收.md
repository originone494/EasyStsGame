# 地图自由选点规格与验收

日期：2026-10-30（Australia/Perth）。按用户最新要求：“地图不使用一条路线的方式，将所有节点尽可能均匀地散布在地图上，玩家可以随意选择节点，当然，也可以直接挑战boss。”用户随后补充：“节点要均匀且散乱，高度不能超过boss节点。”两条一起覆盖步骤8的单线访问方式；上传策划原文和步骤8历史验收记录保留。

## 当前行为

- 地图只显示当前楼层。该层所有未完成节点均可直接进入，包含普通战、配置启用的精英、商店、火堆、事件和Boss，没有节点距离、路径或前置访问要求。
- 普通战确认奖励、安全节点离开后回到本层自由选点，允许先访问靠后的节点，再访问之前跳过的节点。每个节点只完成一次，不可通过重复进入领取奖励。
- 第一、二层Boss成功后仍需确认结果，之后进入下一层；旧层未访问节点保持未完成、不补发金币／属性或卡牌／遗物资格，也不能回到旧层。第三层Boss成功直接通关，不发奖励。
- 战斗／安全节点／结算进行中查看地图只能查看并返回原场景，不能跳出未结束的节点。失败结束本局，仍只能重新开局。
- 每层仍为10／7／5个战斗节点（各含1Boss），另有5个随机非战斗节点且至少1商店、1火堆，再加1个Boss旁固定火堆；全局40节点。固定火堆不是Boss前置条件。安全节点服务尚未实现，不免费治疗或发钱。

## 展示与状态

地图保留羊皮纸、墨线图标和山林／罗盘装饰，移除路径连线、装饰性虚线路径、起终点和方向表达。采用带最小间距的随机散点，不使用规则行列。逐个节点生成256个随机候选，排除会与已有图标／文本重叠的位置，并选择离已有节点较远的候选，使节点散乱且尽量铺开。不同窗口采用独立的宽高参考范围和足够的纸面高度；空间不足时增加高度而不挤压节点。

Boss固定在最高处的中间；所有非Boss节点均放在Boss下方的区域，保留图标与文本间距。额外火堆固定在Boss下方附近，仍可跳过。布局只使用独立种子，地图渲染不推进战斗、天气或牌序随机数。

节点完成后保留原位并显示勾，不删除或重排其他节点。空间不足时地图内滚动，顶部资源栏保留。此前删除的“三层旅程”、进度、楼层切换、说明侧栏和图例不重新出现。

`currentNodeIndex`仅指正在处理的节点；处于地图时为本层未完成节点的兼容定位值，不代表强制的下一节点。进入时由节点ID重新定位；完成普通节点后找本层尚未完成节点，只有Boss成功才更新楼层。节点生成数组的顺序仅用于稳定保存、编号与内容生成，不决定访问顺序。
