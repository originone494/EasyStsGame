## 第一阶段：一场好用的战斗

一维战场、共享生命、左右敌人；7 张初始牌组，回合补牌至 3；弃牌、洗牌、消耗；攻击、抽牌、移动、击退；怪物按距离排序逐只行动；普通怪接触伤害后消失；玩家死亡立即失败，最后击杀须完成卡牌及触发后结算。使用 1 名临时角色、少量测试卡及 3 种不同参数敌人。

验收：能从开战打到胜利或失败，位置、卡牌循环、伤害结果正确。详细规则与固定局面见《第一阶段规则.md》。本阶段不包含招募、地图、商店、天气、遗物、Boss、存档。

## 第二阶段：构筑和 Boss 规则

加入卡牌与遗物触发、事件队列；击退传递与连锁碰撞；晴／雨／风切换和三项适应属性；Boss 接触截止、100% 成功门槛、超额伤害统计；普通战 20% 保底奖励、Boss 最高 5 倍奖励；支持无限连招。

重点验证：多段击杀、最后击杀治疗、连续洗牌、碰撞触发、Boss 超过 100% 后继续受击。第一阶段已实现的单体击退链继续复用；群体同步击退、相反方向同时冲突及碰撞遗物在此阶段加入。

验收：普通战和 Boss 战均可完整游玩，显示评分与实际奖励一致。

## 第三阶段：完整一局

3 层、22 场战斗、线性地图；普通／精英／Boss 奖励；招募角色三选一，3 轮卡牌三选一；商店、火堆、事件；属性楼层上限、升级、删牌；第三层 Boss 成功后直接通关，无奖励；自动存档、继续游戏和重新开局。

验收：从选角色一直玩到通关，中途退出后可以继续。本阶段完成即形成可完整游玩版本。

## 第四阶段：正式内容与平衡

先完成 3 名可玩角色，每名 36 种专属卡及升级效果、1 件固定遗物。招募不足 3 名时展示全部可选角色，后续扩充角色增加变化。

| 内容 | 首批制作目标 |
| --- | --- |
| 可玩角色 | 3 名 |
| 角色专属卡 | 108 种，均有升级版 |
| 普通／精英敌人 | 约 8～12 种 |
| Boss | 3 个 |
| 通用遗物 | 约 18 件 |
| 无色卡 | 约 12 种 |
| 随机事件 | 约 10 个 |

以上为制作目标，不直接覆盖原设计。按机制分批制作，每批加入后实际打一局，避免一次填完内容才发现体系不成立。

验收：不同角色与选牌形成不同打法，全部卡牌有用途，完整流程无明显卡死或必输布局。

## 第五阶段：可交付版本

补齐清晰卡面、目标选择、非法操作提示；怪物行动顺序、移动距离、Boss 进度；晴／雨／风天气、遗物触发、伤害、碰撞动画；教程、音效、设置、结算页；稳定存档及版本兼容处理。

交付游戏源代码、可运行版本、启动说明、内容配置文件，便于修改卡牌、敌人、奖励、商店价格。

## 实施原则

- 规则与界面分离：`game/` 独立计算，界面仅提交操作和显示结果，动画速度不影响结算。
- 内容使用独立配置；抽牌、伤害、奖励去重等所有来源使用同一规则。
- 先完整流程再扩充内容；前三阶段的临时内容必须明确标记。
- 未定细节使用公开、集中的原型默认值；只有与已确认玩法产生冲突才澄清。
- 不提前实现后续阶段的大规模内容。正式设定待 V15.7 原文核对。
