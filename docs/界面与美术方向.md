# 第一阶段界面重制

用户确认的方向：**像素风，但不是地牢**。当前采用野外雾林古道、披风旅人、森林怪物、羊皮纸卡面。此方向是本次界面迭代的选择，不宣称完整策划案已规定世界观。

## 当前实现

- 横向雾林场景：原创像素背景、树林纵深、古道格位、环境萤光。
- 角色与三类敌人使用独立精灵；敌人头顶显示下一次移动、接触伤害、行动次序，脚下显示生命。
- 带原创插画的卡牌：免费标记、卡牌来源、名称、效果、消耗提示；悬停抬起，选中发光。
- 目标锁定、非法操作提示、伤害／治疗／碰撞／位移浮字；胜败结算覆盖层。
- 抽牌／弃牌放在手牌两侧；调试局面和随机种子收进底部折叠入口。
- 桌面优先；窄屏允许横向滚动完整战场；尊重系统减少动态效果设置。

## 素材与维护

素材全部本地保存，没有外部字体或图片请求。

- `public/art/forest.svg`：原创森林源图。
- `src/ui/art.ts`：角色、怪物和卡牌插画的可编辑矢量源。
- `public/art/*.png`：低分辨率像素素材，界面使用 nearest-neighbor 像素放大。
- `scripts/generate-art.mjs`：重新生成素材。使用 Chromium 在离屏画布上栅格化、限制色阶。

重新生成（可选，日常启动不需要）：

```sh
CHROMIUM_PATH=/usr/bin/chromium node scripts/generate-art.mjs
```

本机没有系统 Chromium 时先安装 Playwright 浏览器，再不带 CHROMIUM_PATH 执行脚本。使用 Node.js 24（支持直接载入该 TS 源文件）。

本次仅调整展示和操作反馈，没有修改战斗规则。昼夜切换、地图、Boss、正式动画序列和音效仍按后续阶段开发；背景中的月光仅为美术，不代表已实现昼夜机制。原型题名「隙间行者」也可后续调整。
