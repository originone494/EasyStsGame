# 第一阶段界面重制

用户确认的方向：**像素风，但不是地牢**。当前采用野外雾林古道、披风旅人、森林怪物、羊皮纸卡面。此方向是本次界面迭代的选择，不宣称完整策划案已规定世界观。

## 当前实现

- 横向雾林场景：原创像素背景、树林纵深、古道格位、环境萤光。
- 角色与三类敌人使用独立精灵；敌人头顶显示下一次移动、接触伤害、行动次序，脚下显示生命。
- 带原创插画的卡牌：免费标记、卡牌来源、名称、效果、消耗提示；悬停抬起，选中发光。
- 目标锁定、非法操作返回手牌、伤害／治疗／碰撞／位移浮字；胜败结算覆盖层。
- 完整场景从屏幕左侧铺到右侧，并延伸到卡牌后方；正常尺寸卡牌直接在场景前景扇形重叠，底部四分之一仅为交互判定范围，没有独立手牌面板；抽牌／弃牌放在两侧，调试局面和种子仅通过开发用 URL 参数进入，游戏界面不显示相关文字。
- 支持按住左键拖牌及点击拿牌后再点击使用；目标牌须放到敌人身上，无目标或放回手牌区均返回；右键和 Esc 取消。无目标牌在战场使用；移步牌放到队伍左右的标记。
- 指定敌人的牌拖出底部四分之一范围后隐藏跟手卡面，只显示瞄准箭头及合法目标高亮；移回手牌范围恢复卡面。其他类型卡牌继续显示跟手卡面。取消、失焦和回合切换均清理状态。界面仅在合法放置时调用规则入口，不自行变更牌区和伤害。
- 13 格始终随窗口等分，战场左右边界就是窗口左右边界；窄窗口也不滚动战场。尊重系统减少动态效果设置。

## 素材与维护

素材全部本地保存，没有外部字体或图片请求。

- `public/art/forest.svg`：原创森林源图。
- `src/ui/art.ts`：角色、怪物和卡牌插画的可编辑矢量源。
- `public/art/*.png`：低分辨率像素素材，界面使用 nearest-neighbor 像素放大。
- `scripts/generate-art.mjs`：重新生成素材。使用 Chromium 在离屏画布上栅格化、限制色阶。

重新生成（可选，日常启动不需要）：

```sh
CHROMIUM_PATH=/usr/bin/chromium node scripts/generate-art.mjs
```

本机没有系统 Chromium 时先安装 Playwright 浏览器，再不带 CHROMIUM_PATH 执行脚本。使用 Node.js 24（支持直接载入该 TS 源文件）。

本次仅调整展示和操作反馈，没有修改战斗规则。昼夜切换、地图、Boss、正式动画序列和音效仍按后续阶段开发；背景中的月光仅为美术，不代表已实现昼夜机制。游戏显示名称已改为「简单尖塔」。

## 文字与 HUD 精简

按用户要求删除底部两角说明、手牌上方提示、左上角战斗名称／布局说明、共享生命文字，以及 HUD 人物立绘、姓名与称号；不把这些文字挪到其他位置。左上角角色信息仅保留血条。抽牌堆和弃牌堆下移至屏幕底角，只保留图案与数量。保留文字统一比原样式增大 3px；标题为「简单尖塔」。

## 牌堆查看

抽牌堆、弃牌堆和消耗堆可点击查看，消耗堆入口在弃牌堆旁（✕）。底角仍仅显示图案与数量，名称通过悬停及无障碍标签提供。查看窗口展示完整卡面和每张重复牌，支持三个牌堆切换、空状态、Esc／关闭／遮罩返回与焦点恢复。卡面复用手牌模板，但查看中的牌不能打出。

抽牌堆复制后按牌名展示，不公开实际抽取顺序；弃牌和消耗堆按最近进入优先展示。查看不会修改牌堆或消耗随机数。
