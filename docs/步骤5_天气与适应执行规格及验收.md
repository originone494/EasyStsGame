# 步骤5：天气与适应执行规格及验收

日期：2026-10-30（Australia/Perth）。基线 `4aa8b73`，开发分支 `dev/v15.7-step5-weather`，备份分支 `backup/v15.7-before-step5-20261030`。

## 开发前执行规格

采用用户已确认的晴／雨／风，覆盖旧昼夜设计。每场战斗固定种子随机初始天气，按晴→雨→风→晴循环；每段持续3个完整回合，在第4、7、10……个玩家回合开始时切换。显示的剩余回合包含当前回合，因此第1／2／3回合显示3／2／1，下一回合切换后重新显示3。

自然天气更新及其事件响应先于TURN_STARTED回合开始效果，再补手牌。切换不发生在怪物行动中途；胜负终止后不再切换。初始化天气在第一回合效果前生效，不额外伪造一次天气切换事件。

初始概率尚未作为正式平衡值确定，本次使用可配置的晴／雨／风等权1:1:1开发默认值。天气使用从战斗种子和布局派生的独立随机流，保存其状态，不消耗原有洗牌随机数。相同种子与布局重开，初始天气和抽牌均可复现；自然切换本身不再随机抽取。

三项独立非负整数属性为sunAdaptation、rainAdaptation、windAdaptation。默认均为0。当前天气对应每点提供1%卡牌直接伤害加成，先在线性点数内合计，再作为一个独立倍率进入步骤3统一公式；不提前取整，不把每点拆为多个1.01。其他独立倍率继续相乘，仅最终向上取整一次。

只有card类别受适应加成；relic、indirect、contact和直接生命损失不自动享受天气增伤。全体伤害、多段伤害逐目标、逐段沿用同一伤害公式。属性在战斗状态与初始化选项中独立保存，后续楼层上限及战斗奖励属于下一步骤，不在这里擅自设定增长或上限。

界面增加紧凑只读天气组件，展示图标、天气名、剩余完整回合、当前生效适应和卡牌直伤加成；自然切换时复用战场浮字提示。普通战斗不加入调试控件，旧测试局面保持可进入。

## 实现与配置入口

- `content/weather.ts`：晴雨风名称／图标／对应属性、固定循环、持续回合、初始权重和默认属性。
- `game/weather.ts`：属性校验与原子更新、独立随机流初始化、自然周期、剩余完整回合及当前适应读取。
- `game/state.ts`：保存weather和attributes；createBattle第五参数可指定initialWeather及初始属性，现有四参数接口保持兼容。每场状态复制周期配置，后续修改全局配置不改变已经开始的天气时钟。
- `game/turn.ts`：回合到期监听先失效，然后天气更新及其事件链，再TURN_STARTED及其事件链，最后补牌及抽牌事件。任一处理点致死则不继续后续阶段。
- `game/damage.ts`：仅card类别在计算开始时读取当前适应，把总点数作为单个独立百分比倍率加入统一公式；遗物、间接及接触类别不受此自动加成。
- `ui/weather.ts`：紧凑天气组件；main.ts复用浮字提示。组件位于顶部信息区下方，桌面及窄窗口不占据手牌、目标或结束回合按钮区域。开发事件日志向下避让，普通入口仍不显示调试日志。

新增WEATHER_CHANGED事实，包含from、to和实际切换turn；监听可用weather条件判断当前天气。该事件只在自然切换时产生，初始化不重复触发，重复更新同回合不重复记录。状态及随机流可JSON往返，未增加游戏存档功能。

DamageModifiers新增percentBonuses百分比点数组，每个条目转为精确的`1+点数/100`独立因子。天气对应属性的总点数只加入一个条目。计算沿用步骤3的局部有理数，不先用浮点计算倍率再取整，例如50基础加14%恰好57；基础10乘1.2、1.3并加40%得到ceil(21.84)=22，不是先取整16再乘1.4得23。事件详情保留实际参与的百分比点。

正常牌组、怪物布局、生命和洗牌种子均保持原值；卡面伤害文字明确为基础数值，最终结果再应用适应和其他修正。正常开局三项适应为0，因此天气会自然循环，但需要后续战斗奖励或显式内容提供属性成长。本步骤只实现属性数据与伤害接入，不提前发放金币、属性或卡牌奖励。

## 可操作天气局面

六个开发局面使用1000生命、移动0的普通测试目标，以便观察到第10回合，不代表正式怪物或Boss参数。固定测试手牌仅一张，普通弃牌和补牌规则照常执行。

| URL参数 | 操作与预期 |
| --- | --- |
| `?scenario=weatherSun&debug=events` | 晴，晴／雨／风适应40／20／60；基础10结算14，目标986/1000 |
| `?scenario=weatherRain&debug=events` | 雨，同一组属性只有雨适应20生效；结算12，目标988/1000 |
| `?scenario=weatherWind&debug=events` | 风，同一组属性只有风适应60生效；结算16，目标984/1000 |
| `?scenario=weatherCycle&debug=events` | 初始晴，连续结束回合；第4回合雨、第7回合风、第10回合晴，倒计时按3／2／1循环 |
| `?scenario=weatherMultipliers&debug=events` | 晴40适应，使用倍率攻击：10×1.2×1.3×1.4，结算22，目标978/1000 |
| `?scenario=weatherSources&debug=events` | 晴40适应：卡牌直伤14，遗物与间接触发各10，目标966/1000 |

测试局面重开恢复其预设天气、属性及回合1；切换测试战斗退出固定局面，回到正常随机天气及0适应开局。事件查看器增加weather和attributes，普通入口只显示玩家所需的天气信息。
