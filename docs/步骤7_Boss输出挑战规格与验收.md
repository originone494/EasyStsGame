# 步骤7：Boss输出挑战

日期：2026-10-30（Australia/Perth）。开发前基线`0e0e64b`，开发分支`dev/v15.7-step7-boss`，备份`backup/v15.7-before-step7-20261030`。依据实施方案步骤7及完整策划案6.6、12.3、12.5节，上传原文不修改。

## 开发前执行规格

每场挑战仅有一个明确指定编号的Boss。其正整数生命基准、累计有效伤害与首次接触标记独立存储。经统一公式最终取整后的伤害完整累计，过量不截断，0伤害不增分；小怪伤害不计入Boss评分。达到100%仍可选中、继续承受多段及群体伤害，不产生死亡事件、不触发击杀、不提前胜利。Boss正常受完整击退，继续使用现有实体阻挡和边界规则。

首次尝试前进进入队伍格构成实际接触：先锁定已完成的累计伤害，立即按累计伤害≥基准成功、否则失败判定；接触不扣生命、不产生接触伤害／生命减少事件，不允许待处理接触监听补伤、补治疗或继续小怪行动。已完成的事实保留，余下队列取消。接触前队伍生命归零仍立即失败。

第一、二层成功奖励为`ceil(base × min(accumulatedDamage / baseMaxHp, 5))`，金币与各项适应分别精确计算、只最终取整，再对新增属性应用当前楼层上限。失败不享受普通战20%保底。Boss评分不封顶；500%与600%均最多发5倍基准。固定的稀有卡三选一及通用遗物资格不按评分缩放，实际选卡、遗物池及招募在对应后续步骤实现。

第三层成功仅展示通关及不封顶伤害评分，金币、属性、卡牌、遗物全部不发，不展示奖励区域、无第四层入口。Boss失败提供重新开局入口，不重试本场或继续下一层。地图与完整RunState属于步骤8，本步不声称已完成三层流程。

用户已确认Boss奖励使用可调测试值：满评分100金币＋晴／雨／风适应各10点。

用户明确选择生命减少语义：“先扣生命至0并产生实际生命减少事件；之后只累计伤害，仍不死亡”。因此Boss的`hp`只在0～基准之间，第一次跨过0的伤害会产生当时剩余生命对应的`HP_LOST`；之后伤害仍完整生成`DAMAGE_RESOLVED`并累计输出，`hpLost`为0，不伪造负生命或生命减少。生命为0仍保留实体、可选中、可继续多段攻击、可击退和推进。Boss伤害事实额外记录`bossAccumulatedDamage`，与真实扣血分开查看。

## 实现与界面

- `game/boss.ts`维护独立编号、生命基准、累计伤害、接触标记和达标判断。Boss不加入非Boss评分账本；小怪保留其自身账本，Boss输出只取Boss记录。
- 统一伤害批次先计算所有伤害、实际扣血及Boss新增累计，验证完成后再整体提交。累计或奖励超出可精确表示的安全整数时明确拒绝，不进行部分写入；不以截断累计伤害来限制奖励。
- `content/bossEncounters.ts`提供独立的三层Boss测试布局，基准100、速度1，临时守林者复用重甲兽素材。这些不是正式Boss数值／平衡或完整地图；普通三个布局及其牌序不变。
- `createBossBattle`在开始事件前初始化Boss、奖励配置及携带资产，供步骤8接入。`?battle=boss&floor=1&seed=157`可用正常七张牌组开第一层独立Boss战；floor为1／2／3，非法参数回落为1。正常根入口仍是原普通测试战斗。
- HUD显示累计伤害／基准、不封顶输出评分、达标状态及“接触时结算”；Boss意图显示接触结算，目标下方是输出进度，不把0生命误显示为已死亡。事件日志可查看实际HP减少和独立伤害累计。
- 第一、二层成功的奖励结果保留固定稀有卡三选一及一件通用遗物的资格：第一层普通品质、第二层罕见品质。不假装已有正式卡池、遗物抽取或招募，结果页本步展示实际发放的金币与适应。
- 第三层成功只展示通关及输出，无奖励区域。Boss结果仅提供“重新开局”，清除本次金币、成长与Boss／固定局面参数，回到普通七张牌组初始开局；不重试失败的Boss、不开放第四层或伪造下一层继续。完整地图和RunState仍为步骤8。

## 可操作开发局面

地址参数为`?scenario=...`，追加`&debug=events`可查看Boss记录、事件及领奖状态。所有局面固定初始雨天，避免其他天气适应改变预期伤害。

| scenario | 操作与预期 |
| --- | --- |
| boss99 | 已累计99%，结束回合即接触，失败、0奖励、队伍生命不变 |
| boss100 | 已累计100%，结束回合成功，100金币＋三项适应各10点 |
| boss110 | 110%时打精准终结至120%，仍可操作；结束回合3次接触，120金币＋各12适应 |
| bossPush | 已归零Boss打击退，完整后退2格；第3次结束回合才接触成功 |
| bossMixed | 打同步横扫，小怪死亡，Boss累计4%，继续战斗 |
| bossMinionContact | 结束回合，小怪接触消失扣2生命，Boss继续，输出仍110% |
| boss600 | 第二层600%接触成功，奖励最多500金币；三项适应95各加5至100，分别45点溢出 |
| bossFinal | 第三层600%接触，直接通关，不发任何奖励 |
| bossMulti | 99%时打连击，3段各2均执行至105%；实际扣血为1／0／0，无死亡事件 |
| bossLethal | 110%但先打生命代价，队伍生命归零立即失败，后续治疗取消、0奖励 |

固定开发局面的预置累计与剩余生命保持一致，预置伤害不伪造历史事件。开发卡不进入普通牌组。
