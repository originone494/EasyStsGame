| 双向一维战场、全队共位、共享生命 | 已支持 | `game/model.ts`、`game/state.ts`、`content/encounters.ts`；默认13格、20生命是原型参数 |
| 角色静态配置与队伍成员实例 | 部分支持 | `content/characters.ts`、`BattleState.party`；仅临时角色行者，无选择、正式遗物及招募 |

| 卡牌定义／实际实例／战斗临时状态分离 | 已支持 | `game/model.ts`、`game/deck.ts`；同名复制品ID不同，永久牌组与战斗牌区独立 |

| 任意存活敌人可选，不设射程／阻挡 | 已支持 | `game/actions.ts`；多段目标死亡后停止该目标剩余段 |
| 非法移动不消耗牌、允许重新选择 | 已支持（原型冻结规则） | `game/actions.ts`、`game/movement.ts`；越界或终点被占据拒绝执行 |
| 单体击退、逐格传递、边界停止 | 已支持 | `game/movement.ts`；碰撞不自动造成伤害 |
| 多目标同步击退、复杂碰撞 | 已支持／冲突细则为公开可调整规格 | `game/push.ts`统一处理锁定、同向累加、反向抵消、争格、边界、排序与账本；逐拍整体提交，详见步骤4规格，待定项不冒充正式玩法 |
| 怪物距离／编号排序，逐只完成行动 | 已支持 | `game/turn.ts`、`game/movement.ts`；每轮锁定顺序，受阻停止 |
| 普通怪物接触伤害后消失，接触不算击杀 | 已支持 | `game/movement.ts`、`game/resolution.ts`；接触移除不产生死亡事件 |
| 玩家死亡立即失败、最后击杀完成本牌直接效果 | 已支持 | `game/cards.ts`、`game/resolution.ts`；原有最后击杀治疗用例保留 |
| 最后击杀完整触发链收尾 | 已支持 | `game/eventQueue.ts`、`resolution.ts`；完成直接效果及死亡相关触发链，队列清空后判胜，收尾内致死立即失败 |
| 统一事实事件格式 | 已支持 | `GameEvent`覆盖11种事件，含显式来源、参与者、目标、数值、序号、父事件与连锁权限；原`BattleEvent`只保留浮字兼容 |
| FIFO、登记顺序、遗物资格与非目标数值快照 | 已支持 | `events.ts`、`eventQueue.ts`、`listeners.ts`；目标执行时选择，临时监听显式配置策略，支持停用／恢复／回合到期与次数限制 |
| 固定修正、独立倍率与伤害最终取整 | 已支持 | `game/damage.ts`统一公式，十进制计算只最终取整一次；每目标、每段独立计算，卡牌／遗物／间接／接触分类可筛选修正 |
