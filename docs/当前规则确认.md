## 天气规则的优先级

以本次归档的《简单尖塔 V15.7 后续开发实施方案》第5步为天气与适应属性的当前依据，覆盖旧《游戏策划案_最终整合版_V15.7.md》第8节中的白天／黑夜设计。旧策划案和上传实施方案原文均保留，便于追溯；不再将这一差异列为待确认问题。

- 天气为晴、雨、风，按晴 → 雨 → 风 → 晴自然循环。
- 每场战斗随机初始天气，具体概率仍待配置。
- 每种天气持续3个完整回合，第4、7、10……个玩家回合开始时切换。
- 顺序为天气更新 → 回合开始效果 → 补手牌 → 玩家行动。
- 三项独立属性为 `sunAdaptation`、`rainAdaptation`、`windAdaptation`。
- 当前天气对应的每1点适应提供1%卡牌直接伤害加成。同属性点数线性累加，独立倍率相乘，公式最终向上取整。
- 遗物、碰撞等间接伤害不自动享受适应加成。

天气与属性已在步骤5实现，详见[执行规格与验收](步骤5_天气与适应执行规格及验收.md)。自然切换及其事件链先于 `TURN_STARTED` 和补牌；独立天气随机流不改变原牌序。当前初始概率为可配置的等权1:1:1开发默认值，正常开局三项适应为0；正式天气概率仍待配置。
